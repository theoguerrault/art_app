## 2. Frontend Stack: Svelte 5 & SvelteKit PWA

### 2.1 Svelte 5 & Runes Reactivity
Svelte 5 functions as the UI engine, utilizing **Runes** (`$state`, `$derived`, `$effect`, `$props`) for state management:
- **Direct DOM Updates:** Mutations in state trigger direct DOM update instructions generated by the compiler.
- **Bundle Footprint:** The compiled JavaScript bundle remains under 30 KB (gzipped), ensuring fast parse and execution times on mobile devices.

### 2.2 Feature-Sliced Design (FSD) Architecture
The frontend codebase follows a Domain-Driven / Feature-Sliced structure:
- **`src/lib/features/`**: Domain-specific feature modules (e.g., `artwork/`). Contains:
  - `components/`: Feature components (e.g., `ArtworkCard.svelte`).
  - `logic/`: Headless logic and state management using Svelte 5 Runes.
- **`src/lib/components/ui/`**: Generic, highly reusable components (e.g., `GlossaryBottomSheet.svelte`).
- **`src/lib/core/`**: Transverse utilities (e.g., `theme.svelte.ts`).

### 2.3 SvelteKit & Service Worker (`@vite-pwa/sveltekit`)
- **Hybrid Rendering:** Pre-renders static UI shells at build time. Dynamic routes configure client rendering where needed.
- **Workbox Integration:** Precaches static assets (JS, CSS, fonts) and applies runtime caching (`Stale-While-Revalidate`) for imagery and API payloads.

## 3. Styling & CSS Architecture

### 3.1 Dark Mode Palette & Theme Management
- Theme colors use perceptual `oklch(...)` syntax for uniform contrast.
- Primary background is fixed to `#121212` with primary accent `#FA47FF` for active states and action controls.
- Theme preferences persist in `localStorage` and update `--artwork-hue` dynamically based on the current artwork's movement color token.

### 3.2 Editorial Typography
- **Headings & Titles:** Utilizes `Instrument Serif` for an editorial artwork presentation.
- **Interface & Body:** Utilizes clean geometric sans-serif typefaces (`Inter`, `Outfit`, `Geist`) for UI controls and long-form descriptions.

### 3.3 Layout & View Transitions
- **View Transitions API:** Executes `document.startViewTransition()` to morph view transitions smoothly during page navigation.
- **Aspect Ratio Pre-allocation:** Explicit `aspect-ratio` CSS declarations on artwork card containers prevent Cumulative Layout Shift (**CLS = 0.00**).

## 4. Performance & Web Vitals Targets

| Web Vital Metric | Target Budget | Architectural Strategy |
| :--- | :--- | :--- |
| **LCP** (Largest Contentful Paint) | **< 0.8s** | Preloaded hero image, WebP CDN format, pre-rendered HTML shell, small JS bundle. |
| **INP** (Interaction to Next Paint) | **< 16ms** | Svelte 5 `$state` mutations without virtual DOM diffing or main-thread blocking operations. |
| **CLS** (Cumulative Layout Shift) | **0.00** | Explicit `aspect-ratio` declarations on image placeholders prior to image download. |
| **Lighthouse Score** | **100/100** | PWA manifest, Workbox offline caching, semantic HTML5, ARIA labels, WCAG AA contrast. |
